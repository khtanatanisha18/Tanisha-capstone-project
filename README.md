Banking Payment Pattern Analysis

Project Overview

Banking Payment Pattern Analysis is a Data Science Capstone Project that analyses Indian banking transaction data to understand customer payment behaviour, transaction amounts, payment channels, and spending patterns.

The project uses Python and various data science libraries to perform data cleaning, exploratory data analysis, data visualization, correlation analysis, and basic machine learning.

Dataset Information

* Dataset Name: Indian Banking Transactions
* File Name: indian_banking_transactions.csv
* Total Records: 550,000
* Total Columns: 20
* Data Type: Structured Data

Objectives

* To analyse banking transaction patterns.
* To identify the most frequently used payment channels.
* To compare average transaction amounts.
* To analyse customer spending behaviour.
* To identify missing values and duplicate records.
* To visualize transaction patterns using graphs.
* To apply Linear Regression for transaction amount prediction.

Key Findings

* Mobile_App was the most frequently used payment channel.
* Success was the most common transaction status.
* Web and API had the highest average transaction amounts among payment channels.
* RTGS had the highest average transaction amount among transaction types.
* Medium was the largest spending group.
* Transaction activity was prominent during hours 12–20.

Machine Learning Model

Algorithm: Linear Regression

The model was used to predict transaction amounts.

Model Evaluation:

* Mean Absolute Error (MAE): 44,910.53
* Mean Squared Error (MSE): 17,797,039,550.86
* R² Score: 0.0025

The R² score indicates that the selected features have very limited predictive performance.
